## Реестр

После создания манифестов зарегистрируйте или обновите набор данных:

```powershell
py -m seedling_data registry add --dataset-root data/zks_v0_1 --name zks_v0_1
py -m seedling_data registry validate --dataset zks_v0_1
py -m seedling_data registry summarize --dataset zks_v0_1 --out reports/dataset_summary.md
```

Сформированную сводку нужно приложить к паспорту набора данных. Она включает
количество изображений по выборкам, распределение идентификаторов классов YOLO,
распределение состояний ячеек и распределение типов целевых точек, если
соответствующие манифесты присутствуют.

Команды `seedling_data`, которые пишут файлы, создают рядом с выходом
`artifact_registry.json`, `artifact_registry.csv` и `*.run_snapshot.json`.
Храните эти реестры и снимки запуска вместе с паспортом, чтобы манифесты,
отчёты о дублях, сводки и аргументы команд оставались прослеживаемыми.
