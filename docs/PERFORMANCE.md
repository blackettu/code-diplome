# Быстрые проверки производительности

В проекте есть лёгкие проверки производительности в `tests/performance/`.
Это широкие защитные проверки, а не точные измерения времени:

```powershell
py -B -m unittest discover -s tests/performance
```

Текущие проверки покрывают:

- `batch_predict` на имитаторе детектора и 100 ключах изображений;
- генерацию синтетических сцен и повторные сбросы RL-среды;
- сухой запуск обучения RL на минимальной конфигурации, включая запись
  снимка запуска и реестра артефактов;
- детерминированные шаги эпизода RL-среды на небольших симулированных кассетах.

Пороги намеренно заданы с запасом: они нужны, чтобы ловить случайные
алгоритмические регрессии и тяжёлые импорты в обычном CI.
